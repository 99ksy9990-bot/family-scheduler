# Codex 지시서 — 6단계: 모든 탭 같은 형식으로 새로 (사용자 2026-11-06)

사용자: "각 카테고리별 표시 형식 동일하게 맞추고, 기존대로 하지마".
5단계에서 달력·할 일·설정은 색만 바꿨음 → **구조까지 새로**. 옛 화면 코드·배치를 이어 쓰지 말 것(로직·데이터 함수는 재사용).

## 모든 탭 공통 형식 (우리집 탭과 똑같이)
1. 머리: 작은 회색 한 줄(날짜·개수 등) + 큰 제목 34px bold. 오른쪽 위 + 버튼은 추가할 게 있는 탭만(우리집·달력·할 일).
2. 구역 제목 20px bold, 좌우 20px.
3. 내용은 흰 둥근 묶음 목록(14px)·흰 타일(22px)만. 행: 왼쪽 아이콘/캐릭터 32px, 제목 17px, 아래 보조 13px 회색, 오른쪽 값. 들여쓴 구분선.
4. 배경 #f2f2f7, 떠 있는 유리 탭바(선택=아이콘·글자 파랑). 마지막 항목이 탭에 안 가리게 아래 여백.
5. 빈 상태도 같은 흰 카드 한 장(회색 카드 금지).

## 탭별
- **달력**: `design/mockups/cal.html` 그대로. 머리 "2026년"/"11월", 흰 카드 달력(숫자만, 오늘 파란 원, 선택 연파랑, 일요일·공휴일 빨강), 아래 "11월 12일 목요일" 구역 + 묶음 목록(시간순). 월 넘김은 좌우 밀기 + 머리 옆 작은 화살표.
- **할 일**: `design/mockups/todo.html` 그대로. 머리 "N개 남음"/"할 일", 분류 알약 칩(선택 파랑), 구역 오늘까지/언젠가/끝낸 일, 왼쪽 동그라미 체크, 오른쪽 담당 캐릭터.
- **놀이**: 머리 "오늘 N판"/"놀이", 게임 5개를 2열 흰 타일(우리집 타일과 같은 크기·모양), 각 타일 유리 구슬 안 게임 그림(`design/characters/game/*`) + 이름 + 최고 점수. 게임 본체는 아직 "준비 중" 시트.
- **설정**: 머리 "우리 가족"/"설정", 묶음 목록 구역: 가족(구성원·가족 연결) / 앱(알림·백업) / 정보(버전). 행 왼쪽 32px 둥근 사각 색 아이콘(iOS 설정앱식, 선 아이콘 흰색), 오른쪽 회색 ›. 누르면 시트.
- **일정 추가 시트**: 같은 묶음 목록 형식으로(제목 입력 행, 날짜·시간 행, 하루 종일 스위치 행, 누구 행에 캐릭터 4명, 반복·알림 행). iOS 캘린더 새 이벤트 화면 배치.

## 변경 (사용자 결정, 진행 중 반영): 탭 4개
- 하단 탭: **우리집 · 달력 · 놀이 · 가족** (할 일 탭·설정 탭 없앰).
- 우리집 = 머리 → "지금"(가족 4 타일) → "오늘 남은 일정" → "할 일"(todo.html의 분류 칩 + 묶음 목록, 오늘까지/언젠가/끝낸 일은 접힘). + 버튼 누르면 "일정 / 할 일" 고르기.
- 가족 = 머리 "4명"/"가족", 구역: 구성원(캐릭터 행 4개) / 연결(가족 연결) / 앱(알림·백업) / 정보(버전). 설정앱 형식.
- 탭 아이콘: 집·달력·게임패드·사람 둘(선 아이콘). 할 일 데이터·기능은 그대로 유지(옛 앱과 같은 필드).
