# 5단계 결과 — 우리집

2026-11-06 · 작업 브랜치 `v2` · 기준 `STEP-5-APPLE.md`, 갱신된 `design/mockups/house.html`의 수정 3까지 반영.

## 구현
- 앱 이름·문서 제목·설치 이름을 **우리집**으로 변경. 아이콘 파일·주소·SUITE 글꼴·고정폭 숫자 유지.
- 크림/Hum 테마를 iOS 계열 색으로 교체. 라이트 배경 `#f2f2f7`, 흰 불투명 카드. 다크는 어두운 불투명 카드.
- 수정 3에 따라 배경 색 덩어리·유리 카드 제거. 유리 효과는 가족 구슬·탭 아이콘·상태 태그에 적용. 탭바는 추가 2와 최신 시안대로 떠 있는 반투명 알약 유지.
- 우리집 상단 날짜·34px 제목, 가족 2×2 타일 140px, 가족색 구슬 66px 안 캐릭터 56px. 반사광은 얼굴을 가리지 않게 약하게 적용.
- 진행 중 일정은 가족색 태그와 종료 시각 표시. 실제 데이터에 없는 집 위치 등은 추측하지 않음.
- 오늘 남은 일정은 미래 일정·종일 일정만 묶음 목록으로 표시. 32px 캐릭터와 담당자·시간, 첫 미래 일정 시간은 파랑. 가족 타일을 누르면 지난 일정을 포함한 개인의 오늘 전체 일정 시트 표시.
- 탭 아이콘은 시안 SVG 경로 사용, 40px 유리 버튼. 선택 탭은 파란 유리와 흰 선 아이콘. 탭바 좌우 16px·높이 62px·모서리 31px·하단 안전영역을 고려한 최소 8px 간격. 마지막 항목까지 탭 위로 올려 볼 수 있도록 스크롤 여백 확보.
- 우리집 추가 버튼은 일정 시간을 가리지 않도록 제목 오른쪽에 배치. 설정에서는 추가 버튼 숨김.
- 달력·할 일·설정·추가 폼은 기존 기능과 구조를 유지하며 색·모서리·간격 변경. 가족 연결의 모호한 저장 상태 박스는 로그인·연결 의미를 설명하는 문구로 교체.
- 움직임·투명도 줄이기 환경에서는 유리 아이콘과 탭바를 불투명 표면으로 대체.

## 시안과 조정한 부분
- 시안의 옅은 글자와 파란 글자를 대비 기준에 맞게 진하게 보정. 다크 시안의 흰 카드·흰 글자 조합은 어두운 불투명 카드로 보정.
- 선택 탭의 반사광을 낮춰 흰 선 아이콘이 읽히도록 조정.
- 홈 비교는 시안과 구현을 나란히 캡처. 시안에는 별도 달력·할 일 화면이 없어 해당 화면은 실제 구현의 라이트·다크 상태를 확인.
