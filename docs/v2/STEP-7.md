v2, 푸시·배포 금지. games 폴더는 Claude 담당(수정 금지, 버그 발견 시 보고).

## 1. 문제 수정
- "모두"·여러 명 일정: 글자 동그라미("모","가") 대신 해당 가족 캐릭터를 겹쳐 보여주기(32px 칸 안에 2~4명 작은 얼굴 겹침, 모두면 4명).
- 놀이 탭 "오늘 N판": 게임 끝날 때마다 실제로 올라가는지 확인·수정(gameScores 기록 기준 오늘 날짜 판 수). 테스트 추가.

## 2. 한 사람의 하루 시트 (시안 `design/mockups/m_person.html`)
- 우리집 타일·가족 탭 구성원 행을 누르면 열림. 위: 유리 구슬 캐릭터 96px(지금 표정) + 이름 28px + 지금 상태(파랑).
- 구역 "오늘": 그 사람 일정·근무·자녀시간표·할 일을 시간순 한 목록(일정·근무=색 아이콘, 할 일=체크 동그라미, 바로 완료 가능). "내일"도 같은 형식.
- 행 누르면 기존 편집 시트.

## 4. 추가 (사용자: "달력에서 엄마 근무가 N이 겹치니까 이상하게 표시")
- 원인 추정(Claude, 코드 읽기만): `src/v2/data/schedule.js` 21–31행이 밤샘 근무를 다음 날에도 `carryover` 행("근무 N", 00:00 시작)으로 넣음. N이 연속이면 같은 날 "근무 N"이 두 줄(00:00 이어짐 + 22:00 시작)이 됨.
- 바꿀 것: 이어지는 행은 제목 "근무 N 마침", 시간 "~07:00"(시작 없이 끝만), 흐린 글자. 시작 행은 "22:00 – 내일 07:00". 같은 사람 같은 날 근무 행이 두 개면 시간순으로 붙여 묶음 한 칸 안에 두 줄.
- 달력 날짜 칸에는 영향 없음(숫자만). 우리집 "지금" 상태도 이어지는 근무면 "근무 중 · 07:00까지".
- 실제 백업(엄마 N 연속 날짜)으로 달력 선택일 목록 캡처해 전/후 비교, 테스트 추가.
