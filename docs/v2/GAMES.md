# 오늘우리 미니 게임 기획 (2026-11-05)

사용자 요청: "카드 짝맞추기 같은 진짜 게임들, 뭐 떨어지는 거 받고". 휴대폰 전용(iPhone 16 Pro 393×852), 한 손 터치.
대상: 8세·14세·부모 모두 → 난이도 3단계(쉬움·보통·어려움), 시작 전 "누가 해요?" 캐릭터 선택.

## 공통
- 위치: 하단 탭 **놀이**. 게임 카드 목록 + 가족별 최고 기록판.
- 캐릭터: `public/characters/*` 아이콘 사용. 이기면 '완료' 표정, 지면 '바쁨' 표정.
- 기록: 가족 공유 상태에 `gameScores` 필드 **추가만**(기존 필드 변경 금지). `{ [gameId]: { [memberId]: { best, playedAt } } }`. 옛 앱은 모르는 필드라 그대로 통과(2단계 테스트로 보장됨).
- 소리 없음 기본(켜기 옵션), 진동은 지원 기기만. 움직임 줄이기 설정이면 효과 최소화.
- 외부 게임 라이브러리 없이 React + CSS transform / `<canvas>`로. 화면 꺼지면 일시정지.
- 오리지널 게임만(기존 게임 이름·그림 베끼기 금지).

## 게임 1 — 가족 카드 짝맞추기
- 표정 아이콘 12종으로 카드 짝 찾기. 쉬움 4×3(6쌍) / 보통 4×4 / 어려움 4×5.
- 기록 = 걸린 시간(초, 고정폭 숫자)과 뒤집은 횟수. 적을수록 좋음.

## 게임 2 — 하늘에서 떨어지는 거 받기
- 화면 아래 가족 캐릭터가 바구니를 들고 좌우 이동(손가락 끌기). 위에서 별·하트·해(오늘우리 상징)가 떨어짐 → 받으면 점수. 가끔 비구름 → 받으면 하트(목숨) 1개 감소, 3개 다 잃으면 끝.
- 시간이 갈수록 빨라짐. 쉬움은 비구름 없음(8세용).
- 기록 = 점수.

## 나중 후보 (사용자 확인 전 만들지 않음)
- 두더지 잡기형(가족 얼굴 톡톡), 기억력 순서 맞추기.
