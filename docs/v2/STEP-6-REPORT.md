2026-11-06 · `v2` · `STEP-6-TABS.md`의 변경·추가·시안 확정본 및 후속 게임 연결 지시까지 반영.

## 화면 구성
- 하단은 **우리집·달력·놀이·가족** 네 탭. 26px 선 아이콘, 선택 아이콘·글자만 파랑. 유리 알약 탭바·안전영역·최대 폭 480px 유지.
- 모든 탭에 작은 회색 설명과 34px 큰 제목, 20px 구역 제목, 흰 14px 묶음 목록·22px 타일 적용. 빈 상태도 흰 카드. 다크에서는 불투명 어두운 카드.
- 달력·할 일·가족 첫 화면은 기존 배치에 색만 덧씌우지 않고 JSX를 새로 구성. 일정·반복·담당자·저장·인증 함수는 재사용. 달력과 개인 일정 시트는 공통 `ScheduleList`, 가족은 공통 `GroupedList` 사용. 옛 `Timeline` 화면은 제거하고 로딩·오류 표시만 `DataState`로 분리.
- 우리집: 지금 2×2 가족 타일 → 오늘 남은 일정 → 할 일. 할 일은 분류 칩과 접힌 오늘까지·언젠가·끝낸 일 묶음. 동그라미 체크·오른쪽 담당 캐릭터. 제목을 누르면 수정·삭제 시트, 삭제 되돌리기·분류 관리·반복 회차 기능 유지.
- 달력: 연도/월 머리, 작은 이전·다음 화살표, 흰 달력 카드, 숫자만 표시. 오늘 원·선택 연파랑·일요일/공휴일 빨강. 좌우 밀기로 월 이동, 세로 밀기는 월을 바꾸지 않음. 아래 선택일의 시간순 묶음 목록. 종전 월/주 툴바는 제거.
- 가족: 인원수/가족 머리, 구성원 캐릭터 행, 연결·앱·정보 묶음. 구성원 행을 누르면 해당 구성원의 편집 시트. 관리 버튼에서 추가·숨김·근무·자녀 일정·기념일 등 기존 기능 접근. 알림·백업·버전은 각각 시트.
- 추가: 우리집/달력 +를 누르면 확정 시안처럼 **취소·새 일정·추가** 상단과 **일정/할 일** 전환이 있는 시트. 제목/장소, 종일/시작/종료/여러 날, 가로 캐릭터 선택, 반복/알림 묶음. 기존 일정 분류는 별도 접이식 행으로 보존. 자동 종료 시간·자정 넘김·여러 담당자·반복·알림 저장 형식 유지. 할 일 입력도 같은 시트에서 전환.

## 공개 예시의 분리
- `createDemo(today)`에서 오늘 기준 아빠·엄마·초롱·연두, 일정 6개·할 일 5개·근무 3개를 새로 생성. **실제 백업 내용은 복사하지 않음.**
- 로그인 전에는 예시 배너를 표시하며 누르면 가족 연결 시트로 이동. 예시 수정은 별도 메모리 상태에서만 처리. 예시 일정·할 일·프로필·게임 기록을 저장 함수·가족 동기화에 전달하지 않음.
- 로그인 전 기기 저장 작업도 중지하므로 기존 저장소를 바꾸지 않음. 새로고침 시 예시가 초기화됨.
- 로그인한 사용자의 화면은 실제 기기/가족 데이터로 전환. 인증 사용자가 바뀌면 화면을 새로 만들어 예시에서 열어 둔 입력창·선택값이 실제 저장으로 넘어가지 않게 함. 인증 세션이 남은 오프라인 상태에서는 기기 데이터를 표시.
- 뒤에 추가된 개인정보 지시를 우선해 **화면 캡처에는 공개 예시만 사용**. 실제 백업은 기존 데이터 변환·왕복 보존 검사에서만 검증하고 공개 화면·코드에 넣지 않음.

## 게임 연결
- Claude 담당 `src/v2/features/games/`는 수정하지 않음. `games/index.js`의 `GAMES` 목록으로 이름·그림·lazy 컴포넌트를 읽음. 그림은 `/game/{image}.png`.
- 등록된 짝맞추기·하늘 선물·얼굴 톡톡·순서 기억·그림 셋 맞추기 **5개 모두** 가족 선택 → 난이도 → 게임 시트로 연결. `Suspense` 로딩 상태와 미등록 컴포넌트의 준비 중 대체 유지.
- 하늘 선물의 `player`에는 선택한 프로필의 `dad/mom/big/little` 캐릭터를 전달.
- `onFinish` 결과를 `gameScores[gameId][memberId]`에 저장. 기본 `best`·`playedAt` 구조 유지, `level`·짝맞추기 `moves`·당일 판수 `playsToday` 추가.
- 짝맞추기는 초가 작을수록, 동률이면 뒤집은 횟수가 작을수록 최고 기록. 순서 기억은 단계, 나머지는 점수가 클수록 최고 기록. 날짜가 바뀌면 당일 판수는 새로 집계. 기존 모르는 필드·다른 가족 기록 보존.
- 연결된 가족은 기존 저장 경로로 기록 보존, 예시는 메모리에서만 기록. 보기 전용 계정은 게임을 열 수 있지만 기록 저장 권한이 없으면 안내.
