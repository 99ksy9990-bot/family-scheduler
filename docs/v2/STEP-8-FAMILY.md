# Codex 지시서 — 8단계: 가족 탭 전면 새로 (사용자: "보이는 것, 등록하는 것 다 이상함")

7단계 끝난 뒤 진행. v2, 푸시·배포 금지. **옛 FamilySettingsPanel 구조(칩 8개 + 수정/숨기기 버튼 줄) 폐기.** 데이터 필드·저장 형식은 그대로(옛 앱 호환).
시안: `design/mockups/m_family2.html`(가족 탭), `m_member.html`(어른 상세), `m_kid.html`(아이 상세). 한 장: `26.11.06_가족탭_시안.png`.

## 가족 탭
- 머리 "N명"/"가족", 오른쪽 위 "추가"(파란 글자).
- 구역: 구성원(캐릭터 32px · 이름 · 한 줄 요약 · ›) / 우리 가족 날(기념일·생일, 하트 아이콘) / 연결(가족 연결) / 앱(알림·백업) / 정보(버전). "관리" 버튼 없음.

## 구성원 상세 (행 누르면 오른쪽에서 밀려 들어오는 화면, 시트 아님)
- 위: "‹ 가족" 뒤로, "편집". 가운데 유리 구슬 캐릭터 104px, 이름 28px, "출생연도 · 어른/학년".
- **어른**: 구역 "근무"(근무 유형, 근무표=날짜별 근무) — 근무 데이터가 있는 사람만, 없으면 "근무 추가" 한 줄.
- **아이**: 구역 "학교"(시간표, 학기·방학, 학교 정보) + "학원·활동"(자녀 시간표 항목).
- 구역 "모습": 캐릭터 4개 중 고르기(선택 외 흑백), 대표 색 4개 원.
- 맨 아래 빨간 "구성원 숨기기"(되돌리기 토스트).
- 각 행 누르면 그 항목만 편집하는 화면(같은 묶음 목록 형식). 칩 탭 전환 금지.

## 구성원 추가 ("추가" → 시트)
- 묶음 목록: 이름 입력 / 어른·아이 세그먼트 / 출생연도 / 캐릭터 고르기 / 대표 색. "추가" 버튼은 이름 있을 때만 켜짐. 저장 후 바로 그 사람 상세로.

## 옮기는 것
- "반복 예외"는 가족 설정에서 빼서 일정 편집 시트의 "이 날만 빼기"로.
- "기념일"은 가족 탭 "우리 가족 날" 구역으로.
