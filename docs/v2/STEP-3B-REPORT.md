# 오늘우리 v2 — 3b단계 화면 개편 결과

작성일: 2026-11-05 / 브랜치: v2 / Claude 검수 요청

## 범위와 기준

`STEP-3B-UI.md`, `REVIEW-UI-1.md`, 사용자 확정 `design/mockups/mockup.html`을 읽고 시안을 실제 브라우저로 열어 비교했다. 시안의 첫 오늘 화면·B 달력·일정 추가 시트를 기준으로 구현했다.

- 오늘·달력·일정 추가 화면만 개편.
- 할 일 본문·폼·목록과 설정 화면 및 기존 app.css는 수정하지 않음. 공통 하단 탭은 지시대로 스타일 변경.
- 달력은 최신 확정 B: 숫자만 표시. 시안 HTML에 남아 있는 has 클래스의 날짜별 굵기 차이는 의도적으로 가져오지 않음.
- 원본 mockup.html·기존 디자인 토큰 파일은 수정하지 않음. 시안의 색을 `ui-3b.css`의 토큰으로 정의.
- 휴대폰 전용·최대 480px 가운데 정렬 유지. 푸시·배포 없음.

## 오늘 화면

- 하늘·해·언덕 무대 없음. 날짜/연결 상태 한 줄 헤더와 가족 4명 한 줄.
- 가족 캐릭터 외곽 60px, 이름·상태를 시안 크기와 간격으로 표시. 긴 상태는 잘라내지 않고 줄바꿈 허용.
- 일정은 담당자 색의 연한 바탕 카드, 36px 캐릭터, 52px 시간 열, 10px 간격, 18px 모서리.
- 카드 높이 56px 확인. 지난 일정은 흐리게, 진행 중은 바쁨 표정, 미래 일정은 기본 표정.
- 실제 현재 시각으로 지금 HH:MM 선 표시. 예시 시안의 14:20을 고정값으로 사용하지 않음.
- 일정 개수·내용·순서는 기존 공용 scheduleForDate 결과 그대로 사용.

## 달력 B

- 흰 카드 틀·긴 둥근 타일·점·이름표·개수·일정 유무별 굵기 표시 제거.
- 날짜 칸은 숫자 하나, 높이 44px, 주별 가는 경계선. 날짜 숫자 굵기 400으로 통일.
- 오늘은 노란 원, 선택일은 연한 바탕, 일요일·공휴일은 빨간 숫자, 다른 달은 흐리게.
- 실제 달의 주 수에 따라 35/42칸 계산. 월/주 전환·이전/다음·오늘 복귀 유지.
- 날짜 선택 시 시트 대신 달력 아래 선택일 일정 카드 갱신. 11월 달력과 선택일 목록 시작이 한 화면 안에 보임.
- 달력에서 +를 누르면 선택한 날짜로 일정 추가를 시작.

## 일정 추가 시트

- 손잡이·둥근 닫기 버튼·큰 제목 입력·하단 고정 저장 버튼.
- 날짜 기본 1칸. 여러 날 스위치를 켰을 때만 종료일 표시.
- 하루 종일 기본 꺼짐. 시작·종료 시간을 처음부터 표시.
- 시작 시간 변경 시 종료를 1시간 뒤로 자동 변경. 23:30처럼 자정을 넘으면 다음 날 종료일과 여러 날을 자동 적용.
- 네이티브 date/time 입력을 유지하면서 겉은 날짜/24시간 칩으로 표시. iOS 휠 동작 자체는 네이티브 입력에 맡김.
- 누구 일정인가요?에서 캐릭터를 여러 명 선택. 미선택은 흑백, 선택은 노란 바탕. members와 첫 member 필드에 기존 형태로 저장.
- 장소 입력, 반복·알림 세그먼트 버튼. 기존 매일·10분 전·반복 간격/종료일·일정 분류도 유지.
- 일정 추가 시트 안에는 기본 체크박스·fieldset·select·details 없음. 할 일/설정의 기존 입력은 변경하지 않음.
- 시작/종료일·종료 시간·담당자·반복 종료일 검사 유지. 스크롤해도 저장 버튼은 시트 하단에 유지.

공통 탭은 노란 큰 상자를 제거하고 선택된 아이콘만 채움색과 굵은 라벨로 구분한다. 버튼의 조작 영역을 유지하기 위해 닫기·세그먼트 등은 정적 시안보다 넓은 터치 영역을 제공한다. 월 이동 화살표와 기존 추가 필드는 기능 보존을 위해 남겼다.

- 오늘/선택일 개수 일치·선택일 아래 목록·월/주·오늘 복귀.

각 비교 이미지는 786×852이며 직접 열어 확인했다. 원본 캡처는 mockup-*.png, 구현 캡처는 3b-*.png이다. 전부 Git 제외.

직접 확인:
- 오늘 가족 캐릭터 외곽 60px, 일정 카드 56px, 첫 카드 시작 약 253px.
- 11월 달력 35칸·높이 44px·숫자만·동일 굵기. 가로 넘침 없음.
- 일정 추가의 시작 15:00 → 종료 16:00, 고정 저장 버튼 하단 818px(아래 안전 영역 34px).
