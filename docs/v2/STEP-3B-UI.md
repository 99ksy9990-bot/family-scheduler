## 달력 (사용자 선택: A, 이름표 방식)

## 일정 추가 시트 (시안 마지막 화면)
- 제목 큰 입력 → 날짜 1칸 → 시간 시작~종료 → "하루 종일" 스위치(기본 꺼짐) → "여러 날" 스위치(켜면 종료일 등장).
- 시작 시간 바꾸면 종료 = 시작+1시간 자동.
- "누구 일정인가요?" 캐릭터 4명 선택(여러 명, 선택 안 된 사람 흑백) → 기존 `members`/`member` 필드.
- 장소, 반복·알림은 세그먼트 버튼. 기본 체크박스·fieldset·▶ 펼치기·기본 select 사용 금지.
- 저장 버튼 시트 하단 고정, 시트 위 손잡이, 둥근 닫기 버튼.
- iOS 사파리의 날짜·시간 입력은 네이티브 휠을 쓰되 겉모양은 칩 스타일로.
