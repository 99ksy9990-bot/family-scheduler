# 오늘우리 v2 — 4단계 결과

작성일: 2026-11-05 / 브랜치: v2 / Claude 검수 요청

## 완료 범위

설정·가족 연결을 우선 구현하고 할 일을 연결했다. 푸시·배포는 수행하지 않았으며 Claude 담당으로 남긴다.

### 설정·가족 연결

설정 목록 순서: **가족 연결 → 가족 구성원 → 알림 → 백업·불러오기 → 앱 정보**. 항목을 누르면 바텀시트가 열린다. 설정과 하위 화면은 필요한 시점에 불러온다.

- 가족 연결: 이메일/비밀번호 로그인·회원가입, 로그인 후 초대 코드 참여/가족 만들기, 연결 상태, 초대 코드 복사, 연결 계정과 보기 전용/편집 권한, 일정 프로필 연결, 로그아웃.
- 소유자는 다른 연결 계정의 편집 권한을 변경할 수 있게 표시. 실제 처리·검사는 기존 useFamilySync 함수와 서버 권한 경로를 그대로 사용.
- 충돌 시 가족 서버 내용/이 기기 내용 선택 UI도 기존 acceptRemote/keepLocal 함수와 연결.
- 비밀번호는 폼에서 인증 함수로만 전달하며 기기 저장·파일·보고서에 기록하지 않음.
- 가족 구성원: 이름·관계·구분·캐릭터 이미지 선택·대표색·근무표 사용, 숨기기/다시 표시. 기존 프로필의 추가 필드와 id를 보존. 기존 팔레트의 다른 가족 사용 색은 여유 색이 있는 동안 중복 선택을 막는다.
- 근무 유형 코드·이름·시간·사용 여부, 날짜별 근무 편집.
- 자녀 시간표의 요일·종류·시간, 학기/방학 기간, 학교/담임 연락처, 기념일의 양력/음력·윤달·기준 연도, 반복 예외 편집.
- 위 설정 데이터는 기존 11개 localStorage 키와 기존 공유 상태 필드 그대로 저장.
- 알림은 기존 usePushNotifications에 연결. 미지원·차단·연결 오류·사용 중 상태 안내.
- 백업은 기존 상태 구조의 JSON 내보내기, inspectBackup 기반 미리보기, 적용 전 항목별 개수 표시, 잘못된 파일 거절. 파일에 없는 항목은 유지하고 포함된 항목은 교체.
- 최근 버전 목록과 복원 전 확인 UI를 기존 restoreVersion에 연결.
- 앱 정보에 빌드 버전 표시.

기존 FamilySyncPanel/FamilySettingsPanel 화면을 복사하지 않았다. 새 v2 화면을 만들고 기존 훅·데이터 정리·백업 검사 함수를 직접 재사용했다. Supabase DB·권한·인증 훅은 수정하지 않았다.

### 할 일

- 한 목록과 분류 칩. 분류 추가·이름 변경·미사용 분류 삭제. 사용 중인 분류의 이름을 바꾸면 해당 할 일도 함께 변경.
- 제목·분류·여러 담당자·시작/마감일·시간·알림·반복 규칙 등록/수정.
- 반복 할 일은 오늘부터 이달 말까지 회차별 표시. 기존 recurrence.js 형식과 날짜 계산 재사용. 완료일·제외일을 회차별로 유지.
- 목록과 개수는 같은 taskRows 결과를 사용. 완료한 할 일 보기 옵션 제공.
- 담당 가족 24px 캐릭터, 완료 시 완료 표정을 잠깐 표시. 가족 모두·여러 담당자도 해당 구성원들을 표시.
- 삭제 시 확인창 없이 되돌리기 토스트 하나. 반복 항목 삭제는 반복 전체를 삭제하며 버튼의 접근성 이름에 이를 명시. 되돌리기는 전체 원본을 복구.
- 할 일 탭의 떠 있는 + 버튼은 할 일 추가 폼을 열도록 연결.
- 분류 등 새 최상위 필드와 모르는 확장 필드를 `family-scheduler-v2-metadata`에 추가 저장. 기존 11개 저장 키는 유지. 새로고침 후 분류 유지 검사 통과.

### 아이콘·잔여 화면

- design/icons의 180·192·512 PNG를 public의 같은 파일명으로 교체. favicon-64.png 추가 및 index.html favicon 링크 변경.
- 세 기존 파일명이 같으므로 **기존 앱도 같은 새 아이콘을 사용하게 된다.** manifest는 기존 192/512 경로를 그대로 사용하며 교체된 파일을 가리킨다.
- 네 아이콘의 원본/복사본 바이트 동일성과 실제 크기 180×180·192×192·512×512·64×64 확인.
- 오늘 가족 줄 상태 글은 줄바꿈을 허용하고 말줄임·잘라내기 제거. 실제 백업에서 네 상태 모두 잘림 없음 확인.
- 휴대폰 전용·최대 480px 가운데 정렬·393×852 안전 영역 유지. 놀이 게임은 구현하지 않음.
