# 오늘우리 v2 화면 검수 1차 (Claude, 2026-11-05)

확인 방법: https://oneuluri.vercel.app 을 393×852(iPhone 16 Pro 크기)로 열어 직접 조작·캡처. 기기는 크롬 계열(ego) — **실제 iPhone 사파리 모양은 미확인.**
사용자 지적: "뭐가 사랑스럽다는 거야", "달력 길쭉해서 이상", "일정 추가 시작·종료일 이상".

## 오늘 화면
1. 사랑스러움 없음: 크림 바탕 + 회색 카드 + 원형 아이콘뿐. 캐릭터가 '목록 아이콘' 취급. → 시안 `design/mockups/mockup.html` 왼쪽: 하늘·언덕 무대 위에 가족 4명, 각자 말풍선 상태, 해.
2. 일정 행이 회색 줄 목록 → 담당자 색 연한 바탕 카드 + 큰 캐릭터(36px), 지난 일정은 흐리게, "지금 14:20" 선.
3. 상태 글 잘림("영어 19:…").

## 달력
4. 칸이 세로로 긴 둥근 타일(약 46×76) — 한 달이 화면에 다 안 들어오고 선택일 목록이 밀려남. → 칸 높이 46px, 숫자 원 + 아래 가족색 점(누구 일정인지). 오늘=노란 원, 선택=연한 배경. 한 달+선택일 목록이 한 화면.
5. "6개" 숫자 표시는 정보가 약함 → 가족색 점으로 대체.
6. 일요일·공휴일 빨간 숫자.

## 일정 추가 시트
7. 시작일·종료일이 항상 두 칸: 하루 일정이 대부분인데 매번 같은 날짜 두 개. → "날짜" 한 칸 + "여러 날" 켜면 종료일 등장.
8. "종일 일정"이 기본 켜짐 → 시간 칸이 숨어 있음. 대부분 시간 있는 일정. → 기본 꺼짐, 시간 칸 바로 보임.
9. 종료일·종료 시간 기본값이 시작과 무관(09:00/10:00 고정) → 시작 바꾸면 종료가 1시간 뒤로 따라감.
10. 기본 브라우저 부품 그대로: 파란 체크박스, 회색 테두리 fieldset("함께할 가족" 글자가 선에 걸침), "▶" 삼각형 펼치기, 기본 select. 디자인 토큰 미적용 → 캐릭터 칩·토글 스위치·세그먼트 버튼으로.
11. "함께할 가족"에 캐릭터 없이 글자 칩 → 캐릭터 얼굴 칩(여러 명 선택).
12. 닫기 버튼이 네모 테두리 버튼 → 둥근 아이콘 버튼.
13. 시트가 화면 꽉 차 아래 "저장"이 스크롤해야 보일 수 있음 → 저장 버튼 시트 하단 고정.

## 공통
14. 하단 탭 아이콘·라벨 작고 흐림, 선택 탭만 노란 상자. 시안처럼 선택 탭 아이콘 색만 채우는 방식으로 정리.
