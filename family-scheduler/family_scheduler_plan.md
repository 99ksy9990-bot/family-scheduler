## 0. v11.3 최신 반영 사항

### 홈

- 오늘 일정과 오늘 할 일 카드의 배경 톤을 통일하고, 일정의 포인트는 좌측 컬러 바 중심으로 정리한다.
- 루틴 일정은 민트 컬러 바와 `루틴` 칩으로만 구분한다.
- 일반 일정은 하늘색 컬러 바만 사용하고, 큰 배경은 다른 카드와 동일하게 유지한다.
- 12지신 캐릭터는 이모지 대신 SVG 캐릭터 2.0 스타일로 통일한다.
- 홈 상단 가족 캐릭터와 일정/할 일 카드의 담당자 캐릭터는 동일한 정사각형 기준 안에서 표시한다.
- 교대 근무 요약은 D/E/N/OFF 근무 유형 카드와 동일한 색상 체계로 표시한다.

### 달력

- 달력 날짜 셀의 근무 배지는 원형이 아닌 가로 pill 형태로 표시한다.
- 오늘/선택 날짜는 꽉 찬 배경 대신 테두리 중심으로 강조한다.
- 날짜, 근무 배지, 일정 도트 영역을 고정 높이로 구성해 셀 간 정렬이 흔들리지 않게 한다.
- 선택 날짜 상세 영역은 날짜/공휴일, 근무 현황, 일정 영역으로 분리한다.
- 달력 상세의 루틴/일정 카드도 홈의 오늘 일정 카드와 동일한 배경과 칩 컬러 규칙을 따른다.

### 하단 탭바

- 하단 탭 아이콘은 이모지 대신 SVG 라인 아이콘으로 다시 그린다.
- 모든 탭 아이콘은 동일한 가로/세로 크기 기준을 사용하고, 얇은 선 두께로 통일한다.
- 선택 시 아이콘 확대 효과와 하단 라인은 제거한다.
- 선택 컬러는 히어로 컬러 계열의 하늘색을 사용한다.
- 중앙 추가 버튼은 히어로 그라데이션 배경과 흰색 플러스 SVG를 사용한다.

### 가족

- 가족 관리 메인 메뉴 아이콘은 SVG 아이콘으로 통일한다.
- 가족 멤버 추가/수정 화면에서 권한/역할 선택 기능을 제거한다.
- 멤버 카드 목록에서도 역할 텍스트는 표시하지 않는다.
- 생년월일 입력은 숫자 키패드 입력에 최적화하고, 숫자만 입력되도록 제한한다.
- 생년월일 입력칸은 포커스 시 기존 값을 선택해 빠르게 수정할 수 있게 한다.
- 연/월/일 값은 입력 후 범위에 맞게 보정한다.

### 시간표

- 시간표 편집 행은 교시 블록, 과목명, 선택 색상, 삭제 버튼을 한 행의 연결된 구조로 정리한다.
- 교시 블록은 큰 직사각형 대신 컴팩트한 정사각형 카드로 표현한다.
- 현재 선택된 과목 색상은 과목명 오른쪽에 즉시 표시한다.
- 색상 팔레트는 과목명 아래에 배치하고, 선택된 색상만 얇은 테두리로 강조한다.
- 삭제 버튼은 과목명과 같은 행 오른쪽에 정렬한다.
- 행 사이에 구분선을 넣어 각 교시 섹션을 명확히 분리한다.

## 0. v11.2 핵심 반영 사항

- 하단 탭은 `홈 / 달력 / 등록 / 할일 / 가족` 5개로 유지한다.
- `등록`은 빠른 추가, `가족` 하위 화면은 전체 관리 역할로 분리한다.
- 모든 주요 카드는 `카드 탭 -> 상세 바텀시트 -> 수정/삭제/숨김/알림 변경` 패턴을 따른다.
- 할 일 화면은 빠른 입력 중심으로 단순화한다.
- 할 일 빠른 입력줄은 `새 할 일 추가... +` 구조를 유지하되, `+` 앞에 가족 캐릭터를 작게 배치해 담당자를 빠르게 지정한다.
- 할 일 입력 옵션 줄과 담당자 필터 줄은 제거한다.
- 루틴은 별도 등록 타입에서 제거하고, 일정/할 일 입력폼 안의 `반복` 옵션으로 통합한다.
- 일정 입력폼에는 `반복 일정`과 `완료 체크 필요` 옵션을 둔다.
- 할 일 입력폼에는 `반복 할 일` 옵션을 둔다.
- 반복 규칙은 텍스트 입력이 아니라 `일~토` 요일 선택으로 설정한다.
- 기념일은 이름 수정, 알림, 숨김, 삭제가 가능한 상세 바텀시트로 관리한다.
- 기념일 수정 이름 입력은 한글 조합이 끊기지 않도록 안정화한다.
- 기념일은 생일/생신/결혼기념일/관계 인물에 따라 나이와 주년 표현을 다르게 보여준다.
- 음력 기념일은 `음력 원일 -> 올해 양력 날짜`를 함께 표시한다.
- 근무 유형은 D/E/N/OFF에 고정하지 않고 사용자가 표시명, 시간, 색상, 다음날 종료 여부를 수정한다.
- 달력 근무는 자동 패턴 생성 없이 직접 입력된 근무만 표시한다.
- 샘플 근무는 2026년 5월만 유지하고, 6월 이후 임의 근무는 제거한다.
- 근무 입력 화면과 가족 > 근무 설정에서 입력된 근무를 삭제할 수 있다.
- 달력 상단 `공휴일 / 기념일` 범례는 제거한다.
- 일정/할 일 카드 안의 가족 캐릭터는 테두리와 배경 없이 이모지만 표시한다.
- 상단 가족 요약 아바타는 상태 표시 역할이 있으므로 원형 테두리와 배경을 유지한다.
- 가족 멤버 순서는 길게 눌러 바꿀 수 있고, 홈/할 일 입력 캐릭터/주요 멤버 선택 UI에 동일하게 반영한다.
- 시간표는 자녀별 월~금, 교시, 시간, 과목, 색상을 관리한다.
- 시간표 미리보기와 위젯 미리보기는 `왼쪽 교시/시간 + 월~금 과목` 구조로 통일한다.
- 가족 > 위젯 미리보기는 실제 앱 데이터 기반으로 가족 일정, 근무, 시간표, 기념일, 오늘 할 일을 보여준다.

## 1. 서비스 개요

### 1.1 한 줄 정의

가족의 일정, 할 일, 루틴, 근무, 기념일, 자녀 시간표를 한곳에서 함께 관리하는 가족 전용 스케줄러.

### 1.2 문제 정의

가족 일정은 개인 일정 앱보다 복잡하다. 아이 학원, 부모 근무, 가족 행사, 생일, 음력 생신, 납부일, 준비물, 반복 루틴이 섞여 있고, 항목마다 관리 방식도 다르다.

현재 가족들은 카카오톡, 종이 시간표, 사진, 개인 캘린더, 메모 앱을 함께 사용한다. 이로 인해 누락, 중복 등록, 알림 실패, 담당자 불명확 문제가 생긴다.

### 1.3 제품 목표

| 구분 | 목표 |
|---|---|
| 홈 | 오늘 가족 상황을 5초 안에 파악 |
| 등록 | 일정/할 일/기념일/근무를 빠르게 추가 |
| 관리 | 카드 탭만으로 수정, 삭제, 숨김, 알림 변경 가능 |
| 가족 특화 | 자녀 시간표, 음력 생신, 근무표, 가족 위젯 지원 |
| 확장성 | 병원뿐 아니라 다양한 회사의 근무명을 직접 설정 |

## 2. 핵심 사용자

### 2.1 교대 근무 보호자

- 병원, 소방, 경찰, 매장, 공장 등 근무표가 자주 바뀌는 직군
- D/E/N/OFF 외에도 오전, 오후, 야간, 오픈, 마감 등 회사별 표현이 다름
- 필요 기능: 근무 유형 직접 설정, 날짜별 근무 직접 입력, 잘못 입력한 근무 삭제

### 2.2 자녀 일정이 많은 가족

- 학원, 준비물, 숙제, 학교 시간표, 납부일 관리가 많음
- 아이가 시간표 이미지를 휴대폰 배경화면처럼 쓰는 경우가 있음
- 필요 기능: 자녀별 시간표, 반복 일정, 반복 할 일, 위젯 미리보기

### 2.3 기념일을 챙기는 가족

- 부모님/조부모 생신이 음력인 경우가 많음
- 생일은 몇 살인지, 결혼기념일은 몇 주년인지 알고 싶음
- 필요 기능: 음력 입력, 올해 양력 변환, 만 나이/주년 자동 계산, 알림 프리셋

## 3. 핵심 개념

### 3.1 일정

시간이 있는 사건이다. 날짜, 시간, 장소, 참여자가 중요하다.

예:
- 수아 영어학원 16:00~17:30
- 아빠 출장 08:00
- 가족 영화 관람 14:00

### 3.2 할 일

완료 여부가 핵심인 항목이다. 담당자, 마감, 완료 상태가 중요하다.

예:
- 주말 장보기
- 자동차 보험 갱신
- 학원비 납부

### 3.3 반복

반복되는 행동은 별도 등록 타입이 아니라 일정 또는 할 일의 옵션으로 관리한다.

| 유형 | 설명 | 예시 | 표시 위치 |
|---|---|---|---|
| 반복 할 일 | 완료 체크가 필요한 반복 항목 | 물통 챙기기, 약 먹기 | 홈 오늘 할 일, 할 일 탭 |
| 반복 일정 | 시간이 있는 반복 항목 | 매주 화/목 영어학원 | 홈 오늘 일정, 달력 |
| 반복 일정 + 완료 체크 | 일정에도 보이고 할 일에도 체크가 필요한 항목 | 학원 출석 체크, 준비물 있는 수업 | 홈 오늘 일정, 홈 오늘 할 일, 달력 |

반복 규칙은 `일 월 화 수 목 금 토` 요일 선택으로 설정한다. 저장 문구는 `매일`, `평일`, `주말`, `매주 화·목`처럼 자동 생성한다.

### 3.4 기념일

완료 체크보다 기억과 알림이 중요한 날짜다.

타입별 표현:
- 아이 생일: `만 5세 되는 날`
- 성인 생일: `만 38세`
- 부모님 생신: `68번째 생신 / 만 68세`
- 결혼기념일: `결혼 10주년`

자동 생성 기념일:
- 가족 멤버 생년월일에서 만들어진 생일
- 삭제보다 숨김을 우선 제공
- 수정은 멤버 정보에서 하는 흐름을 안내

직접 추가 기념일:
- 이름, 날짜, 음력 여부, 기준 연도, 알림, 숨김, 삭제 가능

### 3.5 근무

가족 멤버의 특정 날짜 근무 상태다.

근무 유형 예:
- D / Day / 07:30~15:30
- E / Evening / 15:30~23:30
- N / Night / 23:30~07:30 / 다음날 종료
- OFF / 휴무
- 오픈 / 09:00~18:00
- 마감 / 14:00~23:00

근무는 자동 패턴으로 생성하지 않는다. 사용자가 날짜별로 직접 입력한 근무만 달력에 표시한다.

## 5. 화면별 기획

## 5.1 홈

### 역할

오늘 가족 상황을 가장 빠르게 파악하는 실행 화면이다.

### 구성

- 가족 오늘 요약
- 오늘 일정
- 오늘 할 일·루틴
- 교대 근무 요약
- 다가오는 일정
- 다가오는 기념일

### 디자인 규칙

- 상단 가족 요약 아바타는 원형 배경과 테두리를 유지한다.
- 일정/할 일 카드 안의 가족 캐릭터는 테두리와 배경 없이 이모지만 표시한다.
- 일정 카드는 탭하면 상세 바텀시트가 열린다.
- 홈 기념일은 최대 2개만 보여주고 전체보기로 관리 화면에 연결한다.

---

## 5.2 달력

### 역할

날짜 중심으로 가족 일정과 근무를 확인하는 화면이다.

### 구성

- 월 이동
- 요일 헤더
- 월간 날짜 그리드
- 선택 날짜 상세
- 일정 추가
- 근무 입력

### 최신 결정

- 상단 `공휴일 / 기념일` 범례는 제거한다.
- 공휴일은 날짜 색상과 선택 날짜 상세의 공휴일명으로 표현한다.
- 기념일은 도트와 선택 날짜 상세에서 표현한다.
- 근무는 직접 입력된 날짜에만 뱃지를 표시한다.
- 2026년 5월 샘플 근무만 유지한다.
- 6월 이후 임의 근무는 표시하지 않는다.
- 날짜별 근무 입력 패널에서 현재 근무를 삭제할 수 있다.

## 5.3 등록

### 역할

새 항목을 빠르게 추가하는 화면이다.

### 등록 타입

- 일정
- 할 일
- 기념일
- 근무

### 일정 등록

일정 기본 필드:
- 이름
- 날짜
- 시작 시간 / 종료 시간
- 장소
- 참여 가족

일정 옵션:
- 반복 일정 ON/OFF
- 완료 체크 필요 ON/OFF

반복 일정 ON:
- 일~토 요일 선택
- 선택 결과를 `평일`, `주말`, `매일`, `매주 월·수`로 자동 표시

완료 체크 필요 ON:
- 저장 시 같은 제목의 할 일이 함께 생성된다.
- 반복 일정도 켜져 있으면 반복 할 일로 함께 생성된다.

### 할 일 등록

할 일 기본 필드:
- 이름
- 담당자

할 일 옵션:
- 반복 할 일 ON/OFF
- 반복 요일 선택

### 근무 등록

- 근무자 선택
- 날짜 선택
- 근무 유형 선택
- 기존 입력 근무가 있으면 `근무 삭제` 가능

## 5.4 할일

### 역할

오늘 해야 할 일과 체크형 루틴을 실행하고 관리하는 화면이다.

### 탭

- 오늘
- 예정
- 루틴
- 완료

### 빠른 입력

입력창은 단순하게 유지한다.

```text
새 할 일 추가...   [가족 캐릭터들]   +
```

규칙:
- 캐릭터를 선택하지 않고 `+`를 누르면 `담당자 없음 · 오늘`으로 추가
- 캐릭터를 선택하고 `+`를 누르면 해당 가족 담당의 오늘 할 일로 추가
- 가족 캐릭터는 가족 멤버 관리의 등록/정렬 순서를 따른다.
- 별도 입력 옵션 줄은 두지 않는다.
- 담당자, 마감, 루틴, 알림의 세부 수정은 카드 상세/수정 바텀시트에서 한다.

### 카드

카드 표시:
- 체크 원
- 제목
- 루틴 태그
- 담당자/마감 또는 반복 규칙
- 가족 캐릭터
- 상세 진입 화살표

카드 탭 상세:
- 일반 할 일: 완료, 수정, 담당자 변경, 내일로 미루기, 삭제
- 루틴: 완료, 오늘만 건너뛰기, 반복 수정, 루틴 끄기, 삭제

삭제는 카드 우측에 바로 노출하지 않고 상세 안에 둔다.

## 7. 근무 설정

### 근무 유형 관리

필드:
- 유형명
- 달력 표시명
- 시작 시간
- 종료 시간
- 다음날 종료 여부
- 색상
- 사용 여부

### 입력된 근무 관리

가능한 액션:

### 달력 근무 입력

달력 날짜 선택 후 근무 버튼을 누르면 해당 날짜 근무를 입력한다.

가능한 액션:
- 근무 유형 선택
- 현재 날짜 근무 삭제
- 선택 후 다음 날로 자동 이동

## 8. 기념일 관리

### 역할

가족 생일, 관계 인물 생신, 결혼기념일, 커스텀 기념일을 관리한다.

### 목록 카드

표시:
- 날짜
- 이름
- 타입 태그
- 음력 태그
- 자동 생성/직접 추가 태그
- 나이/주년
- D-day

### 상세 바텀시트

액션:
- 수정
- 알림 변경
- 홈/달력에서 숨기기
- 삭제

자동 생성 기념일:
- 삭제 대신 숨김 제공
- 멤버 정보에서 수정 안내

### 수정 폼

- 이름 수정 가능
- 한글 자음/모음 조합이 끊기지 않도록 입력 안정성 확보
- 음력 여부, 날짜, 기준 연도, 알림, 홈 표시, 달력 표시, 나이 숨김 수정 가능

## 9. 시간표 관리

### 역할

자녀별 월~금 시간표를 관리하고, 배경화면처럼 볼 수 있는 미리보기를 제공한다.

### 편집 필드

- 자녀
- 요일
- 교시
- 시간
- 과목
- 색상

### 미리보기 구조

```text
시간 | 월 | 화 | 수 | 목 | 금
1교시
09:00 | 국어 | 사회 | 영어 | 수학 | 국어
```

규칙:
- 시간은 왼쪽 열에만 표시한다.
- `1교시`, `09:00`, 요일, 과목은 모두 중앙 정렬한다.
- 시간표 관리 화면과 위젯 미리보기는 같은 구조를 사용한다.

---

## 10. 위젯 미리보기

### 역할

실제 홈 화면 위젯에 올릴 정보를 앱 안에서 미리 보는 화면이다.

### 위젯 종류

| 위젯 | 내용 |
|---|---|
| 가족 일정 | 오늘 일정, 참여 멤버, 시간 |
| 근무 | 오늘/내일/모레 근무 |
| 시간표 | 왼쪽 교시/시간 + 월~금 과목 |
| 기념일 | 가까운 기념일, D-day, 나이/주년 |
| 오늘 할 일 | 오늘 남은 할 일과 루틴 |

### 최신 반영

- 시간표 위젯을 배경화면형 시간표 구조로 교체했다.
- 실제 시간표 데이터 기반으로 월~금 과목을 표시한다.
- 시간은 각 과목 칸마다 반복하지 않고 왼쪽 열에만 표시한다.

---

## 11. 공통 UX 원칙

1. 홈은 오늘의 실행판이다.
2. 달력은 날짜별 확인과 근무 입력에 집중한다.
3. 등록은 빠른 추가 화면이다.
4. 할 일은 빠른 체크와 간단한 추가에 집중한다.
5. 세부 설정은 카드 상세/수정 바텀시트에서 한다.
6. 모든 카드는 누르면 관리할 수 있어야 한다.
7. 자동 생성 항목은 삭제보다 숨김을 우선한다.
8. 근무는 사용자가 직접 입력한 것만 표시한다.
9. 카드 안 캐릭터는 보조 정보이므로 배경/테두리 없이 가볍게 표시한다.
10. 가족 순서는 모든 화면에서 일관되게 반영한다.
